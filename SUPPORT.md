# Support

When reporting a Nostrodomus issue, include:

1. Nostrodomus version.
2. Home Assistant/frontend version if known.
3. Browser and OS.
4. The exact editor/card where it happened.
5. A redacted diagnostics report from Nostrodomus Settings → Diagnostics → Copy full report.
6. Whether `window.__nostrodomus.health()` reports warnings.

Do not include secrets, tokens, private URLs, or full Home Assistant YAML unless you have redacted it.
