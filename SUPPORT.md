# Support

Report a problem at <https://github.com/Views2k/nostrodomus/issues>. First check [docs/KNOWN_ISSUES.md](docs/KNOWN_ISSUES.md) and the troubleshooting table in [DOCUMENTATION.md](DOCUMENTATION.md#troubleshooting).

Include:

1. The Nostrodomus version (Settings, Diagnostics, System Status).
2. The Home Assistant version.
3. Browser and operating system.
4. The editor where it happened (card editor and card type, automation, script, or Developer Tools).
5. A redacted diagnostics report: Nostrodomus Settings, Diagnostics, Copy full report.
6. Whether `window.__nostrodomus.health()` in the browser console reports warnings.

Do not include secrets, tokens, private URLs, or full Home Assistant YAML unless you have redacted it.
